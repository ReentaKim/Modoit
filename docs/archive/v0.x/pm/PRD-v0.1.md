| 항목 | 내용 |

| 버전 | v0.1 (MVP) |
| 작성 | PM |
| 최종 수정 | 2026-11-07 |

## 1. 배경
- Apple 기본 메모 앱은 깔끔하지만 두 가지가 아쉽다. 바탕화면에 붙여 두는 스티키 노트가 없고, Notion처럼 빠르게 서식을 넣는 단축 입력이 약하다.
- 반대로 Notion은 무겁고, 메모가 클라우드에 갇혀 있다.
- 그래서 **Apple 메모의 단정함 + 스티키 노트 + Notion식 단축 입력 + 내 폴더에 저장되는 파일**을 하나로 묶은 메모 앱을 만든다.

## 2. 목표 / 비목표

**목표 (v0.1)**
1. macOS에서 Apple 메모와 비슷한 감성의 3단 메모 화면을 제공한다.
2. 메모와 같은 저장 폴더를 쓰는 스티키 노트를 바탕화면에 띄운다.
3. Notion식 단축 입력(`- `, `[ ] `, Tab 들여쓰기 등)을 지원한다.
4. 사용자가 고른 폴더에 모든 메모를 표준 `.md` 파일로 저장한다.

**비목표 (v0.1에서 하지 않음)**
- 클라우드 동기화, 공유, 협업
- 이미지·파일 첨부, 표, 글자색처럼 Markdown 표준에 없는 서식
- Windows 정식 출시 (구조는 대비하되 빌드·검증은 v0.3 이후)
- 폴더 이름 변경·삭제, 메모를 다른 폴더로 옮기기

## 3. 대상 사용자
- 1차 사용자: 제작자 본인. 업무와 개인 메모를 빠르게 적고, 할 일을 바탕화면에 붙여 두고 싶어 한다.
- 2차 사용자: 메모를 자기 폴더에 파일로 갖고 있고 싶은 macOS 사용자

## 4. 기능 요구사항

| ID | 요구사항 | 우선순위 | 수용 기준 |
|---|---|---|---|
| FR-01 | 첫 실행 때 저장 폴더를 선택한다 | 필수 | 저장 폴더가 없으면 환영 화면과 "저장 폴더 선택" 버튼이 나온다. 고르면 3단 화면으로 넘어간다 |
| FR-02 | 저장 폴더를 바꾼다 | 필수 | 사이드바 아래 폴더 이름을 누르면 다시 고를 수 있다. 앱을 다시 실행해도 유지된다 |
| FR-03 | 빈 저장 폴더에는 기본 폴더 "메모"를 만든다 | 보통 | 빈 폴더를 고르면 `메모/` 하위 폴더가 생긴다 |
| FR-04 | 3단 화면: 폴더 / 메모 목록 / 편집기 | 필수 | 사이드바에 "모든 메모"와 하위 폴더별 개수가 보인다 |
| FR-05 | 메모 목록은 최근 수정 순서로, 날짜 그룹으로 나눠 보여 준다 | 필수 | 오늘 / 어제 / 지난 7일 / 지난 30일 / 연도 그룹. 각 행에 제목, 날짜, 미리보기가 나온다 |
| FR-06 | 새 메모를 만든다 | 필수 | ⌘N 또는 목록의 작성 버튼. 지금 고른 폴더(없으면 "메모")에 생기고 바로 커서가 들어간다 |
| FR-07 | 자동 저장 | 필수 | 입력을 멈추고 0.5초 뒤 저장된다. 메모를 바꾸거나 창을 닫을 때도 남은 내용을 저장한다 |
| FR-08 | 첫 줄이 제목이 되고 파일 이름도 따라간다 | 필수 | 첫 줄을 "장보기"로 쓰면 파일이 `장보기.md`가 된다. 이름이 겹치면 ` 2`, ` 3`을 붙인다. 파일 이름에 쓸 수 없는 문자는 공백으로 바꾼다 |
| FR-09 | 메모 삭제 | 필수 | 편집기 오른쪽 위 휴지통 버튼을 누르면 시스템 휴지통으로 간다(복구 가능). 다음 메모가 선택된다 |
| FR-10 | 아무것도 쓰지 않은 새 메모는 남기지 않는다 | 보통 | 빈 메모에서 다른 메모로 옮기면 그 빈 메모는 휴지통으로 간다 |
| FR-11 | 검색 | 필수 | ⌘F로 검색창에 들어간다. 제목, 미리보기, 경로에서 찾는다. Esc로 지운다 |
| FR-12 | 새 폴더 | 보통 | 사이드바 "+"를 누르고 이름을 입력한 뒤 Enter |
| FR-13 | Notion식 단축 입력 | 필수 | `- `/`* ` → 점 목록, `1. ` → 번호 목록, `[ ] `/`[] ` → 체크박스, `[x] ` → 체크된 체크박스, `# `~`### ` → 제목, `> ` → 인용, ```` ``` ```` → 코드 블록, `---` → 구분선 |
| FR-14 | Tab / Shift+Tab 들여쓰기 | 필수 | 목록과 체크박스 안에서는 한 단계 들어가고 나온다. 목록 밖에서는 들여쓰기 공백을 넣는다. 어느 경우에도 포커스가 편집기 밖으로 빠지지 않는다 |
| FR-15 | 체크박스를 누르면 완료 표시 | 필수 | 누르면 체크되고 글자가 흐려진다. 파일에는 `- [x]`로 저장된다 |
| FR-16 | 새 스티키 노트 | 필수 | ⌘⇧N 또는 사이드바 스티키 "+". 테두리 없는 작은 창이 뜨고 바로 입력할 수 있다 |
| FR-17 | 스티키 색 5가지 | 필수 | 노랑, 분홍, 파랑, 초록, 보라. 마우스를 올리면 상단 막대에 나타난다 |
| FR-18 | 스티키 "항상 위에 고정" | 필수 | 핀 버튼으로 켜고 끈다 |
| FR-19 | 스티키 위치·크기·색·고정 상태 기억 | 필수 | 옮기거나 크기를 바꾼 뒤 앱을 다시 실행해도 그대로 복원된다 |
| FR-20 | 스티키 닫기 / 다시 열기 / 삭제 | 필수 | 닫아도 내용은 남는다. 사이드바 목록에서 다시 연다. 행의 × 버튼으로 휴지통에 보낸다 |
| FR-21 | 앱을 실행하면 열려 있던 스티키를 다시 띄운다 | 필수 | 닫지 않은 스티키는 실행할 때 자동으로 뜬다 |
| FR-22 | 다른 프로그램에서 바꾼 내용 반영 | 보통 | Finder나 다른 편집기에서 파일을 고치거나 지우면 목록과 편집기에 반영된다 |

## 5. 비기능 요구사항

| ID | 요구사항 | 기준 |
|---|---|---|
| NFR-01 | 데이터 소유 | 메모는 사용자 폴더에 표준 Markdown으로만 저장한다. 앱이 없어도 텍스트 편집기로 읽을 수 있어야 한다 |
| NFR-02 | 데이터 안전 | 쓰는 도중 앱이 종료되어도 원본 파일이 깨지지 않는다(원자적 쓰기). 삭제는 휴지통을 거친다 |
| NFR-03 | 보안 | 앱은 저장 폴더 밖의 파일을 읽거나 쓰지 않는다(`..`, 절대 경로, 심볼릭 링크 우회 차단) |
| NFR-04 | 디자인 | Apple 메모와 같은 계열의 시각 언어를 쓴다. 라이트·다크 모드를 자동으로 따른다. Apple 아이콘과 이미지는 쓰지 않는다 |
| NFR-05 | 성능 | 앱 크기 20MB 이하. 메모 수백 개에서 목록과 검색이 즉시 반응한다 |
| NFR-06 | 이식성 | Windows 빌드를 막는 macOS 전용 코드는 `cfg`로 분리한다 |
| NFR-07 | 법적 위험 최소화 | 이름은 상표 충돌을 확인했다. 비공개 앱을 역분석하지 않고, 관찰과 공개 가이드라인(HIG)만 참고한다 |
