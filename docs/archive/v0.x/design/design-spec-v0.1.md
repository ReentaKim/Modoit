## 1. 디자인 원칙
1. **메모 앱 계열의 단정함**: 내용이 주인공이다. 장식은 최소로 하고, 구분은 선이 아닌 여백과 배경 명도로 한다.
2. **macOS 기본 재질 사용**: 사이드바는 시스템 반투명 효과(vibrancy)를, 글꼴은 시스템 폰트를 쓴다.
3. **노란색 하나만 강조색으로**: 선택 상태, 체크박스, 커서에만 쓴다.
4. **스티키는 종이 같은 느낌**: 버튼은 마우스를 올렸을 때만 드러나고, 평소에는 색과 글만 보인다.
5. **Apple 자산 미사용**: 아이콘은 직접 그린 선 아이콘이다. SF Symbols, Apple 이미지, 스크린샷 요소를 쓰지 않는다.

> 참고 방식: Apple 메모 앱은 공개된 화면을 관찰하고 Apple Human Interface Guidelines만 참고한다. 앱 내부(바이너리, 리소스)는 열어 보지 않는다.

## 5. 컴포넌트

- **체크박스**: 지름 18px 원, 테두리 1.5px 회색. 체크하면 강조색으로 채우고 흰 체크 표시를 넣는다. 완료된 항목 글자는 `--text-3`으로 흐리게 한다(취소선 없음).
- **메모 목록 행**: 제목(굵게, 한 줄) / 날짜 + 미리보기(한 줄) / "모든 메모"에서는 소속 폴더. 선택하면 노란 배경이고 위아래 구분선을 숨긴다.
- **날짜 표기**: 오늘이면 "오후 4:16", 어제면 "어제", 그 이전은 "2026. 11. 3."
- **빈 상태**: 목록이 비면 "메모 없음", 검색 결과가 없으면 "검색 결과가 없습니다", 편집기는 "메모를 선택하거나 ⌘N으로 새로 만드세요"
- **스티키 창**: 모서리 10px, 테두리 없음, 시스템 그림자. 상단 24px 막대가 끌기 영역이다. 막대 안의 색 점 5개와 핀·닫기 버튼은 마우스를 올렸을 때만 보인다. 핀이 켜져 있으면 핀은 항상 보인다.
- **환영 화면**: 노란 64px 둥근 사각형 마크, 제목, 설명 두 줄, 강조색 버튼 하나

## 6. 상호작용

| 동작 | 결과 |
|---|---|
| ⌘N / ⌘⇧N / ⌘F | 새 메모 / 새 스티키 / 검색 |
| 편집기 빈 곳 클릭 | 문서 끝으로 커서 이동 |
| 단축 입력 | PRD FR-13 표와 같다 |
| Tab / Shift+Tab | PRD FR-14와 같다 |
| 스티키 막대 끌기 | 창 이동. 300ms 뒤 위치 저장 |
| 스티키 가장자리 끌기 | 크기 조절. 최소 160×120 |

- 강조색 위의 글자 대비: 버튼은 진한 글자(#1D1D1F)를 쓴다.
