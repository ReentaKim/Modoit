#요소 · 동작근거
1빨간 버튼은 닫기가 아니라 숨기기. 앱과 스티키는 계속 동작. Dock 아이콘, ⌘0, 스티키의 "메인 창에서 열기"로 다시 보임. 숨기기 전에 입력 저장.F-02 FR-42, R-1
2사이드바 접기·펴기. ⌥⌘S. 상태 기억.F-02 FR-25
3"모든 메모"는 전체 수, 폴더는 바로 안의 메모 수. 폴더: 펼치기·접기, 우클릭(새 하위 폴더, 이름 변경, 아래에 구분선 추가, 휴지통으로), 끌어 놓기(위 = 안으로, 사이 = 순서).F-03 FR-26~28, R-1
4구분선. 끌어서 옮기고 우클릭으로 지움. 정렬은 구분선 구역 안에서만.F-03 FR-29
5스티키 메모(v0.x "꺼내 둔 메모"): 지금 떠 있는 스티키만, 색 점과 함께. 오른쪽 핀 = 그 스티키의 항상 위 켜기·끄기(켜지면 진한 핀, 스티키 막대의 핀과 같은 상태). 마우스를 올리면 다시 넣기 버튼. 우클릭: 다시 넣기, 색·위치 기억 지우기.F-08 FR-31, FR-44, FR-55
6저장 폴더 이름. 누르면 폴더 변경(저장 못 한 입력이 있으면 DLG-02).F-01 FR-02
7검색. ⌘F로 커서. 지금 보는 범위에서 제목·미리보기·경로. Esc로 지움.F-09
8정렬(수정일순·만든 날짜순·이름순), 새 메모(⌘N, 지금 폴더에, 검색어 지움).F-04 FR-39, F-05 FR-06
9"즐겨찾기" 그룹은 항상 맨 위(지금 폴더 안의 즐겨찾기). 우클릭으로 즐겨찾기에 추가·해제(⌘⇧P).F-04 FR-35, R-7
10날짜 그룹(오늘·어제·지난 7일·지난 30일·연도). 행: 제목, 날짜(정렬 기준을 따름), 미리보기, 떠 있으면 색 점. 행을 사이드바 폴더로 끌면 이동. 우클릭: 즐겨찾기, 꺼내기·넣기, 색·위치 기억 지우기, 휴지통.F-04 FR-05, FR-36, R-2
11별 = 즐겨찾기 켜기·끄기(켜지면 채워진 별). 스티키로 꺼내기 ↔ 다시 넣기 토글(⌘⇧S). 휴지통(시스템 휴지통, 다음 메모 선택).F-04 FR-54, F-08 FR-30, F-05 FR-09
12만든 날 · 고친 날. 앱이 저장해도 만든 날은 그대로.F-04 FR-47
13지원하지 않는 서식이 있으면 읽기 전용 안내(MSG-02). "그래도 편집"을 눌러야 편집.F-06 FR-43
14저장 실패 안내(MSG-01). 3초마다 재시도, 성공하면 사라짐.F-07, Brief 3.2-5
15본문: 첫 줄이 제목이자 파일 이름. 단축 입력(- [ ] # | > …), / 메뉴, 체크박스, 토글, 표, 이미지. TipTap 편집기(앱 내장).F-05, F-06
16즐겨찾기: 누르면 모든 폴더의 즐겨찾기 메모만 목록에 보임. 숫자는 즐겨찾기 메모 수. "고정"이라는 말은 스티키의 항상 위에만 쓴다.F-04 FR-54, R-6
—"종료 멈춤 안내" 상태: 저장 못 한 메모가 있어 종료를 한 번 멈춤(MSG-04, 10초).F-12 R-2

SCR-04 TipTap (표·토글이 있음)
#요소 · 동작근거
1막대 버튼: 핀(항상 위), ↗ 메인 창에서 열기, ✕ 다시 넣기. 비활성 패널에서도 항상 보임. ✕를 눌러도 저장 못 한 입력이 있으면 넣지 않고 안내(MSG-05). ⌘⇧N으로 만든 빈 스티키만 ✕ 때 휴지통으로.F-08 R-5, R-7
2색 견본 5개(노랑·분홍·파랑·초록·보라). 마우스를 올릴 때만 보임. 처음 꺼내면 노랑, 280×280.F-08 R-4
3네이티브가 그리는 서식: 문단, 제목 1~3, 점·번호 목록, 체크박스, 굵게, 기울임, 인용, 구분선, 링크, 인라인 코드, 취소선. 단축 입력 결과는 메인 편집기와 같음. 고친 줄만 다시 씀.F-08 3.2, FR-51, R-9 (D-12)
4표·토글·코드 블록·이미지가 하나라도 있으면 TipTap으로 엶. 네이티브에서 / 메뉴로 이런 서식을 고르면 입력 저장 후 TipTap으로 바뀌고 커서를 이어 감. 열려 있는 동안 TipTap → 네이티브로는 바꾸지 않음.F-08 FR-52, R-10, R-11
—패널: 눌러도 다른 앱의 포커스를 뺏지 않음. 모든 데스크톱·전체 화면 앱 위. 옮기거나 크기를 바꾸면 멈춘 뒤 한 번 저장. 모니터 밖이면 기본 위치로 복원.F-08 FR-40, R-8
—디자인 검토: 두 스티키의 막대, 여백, 글꼴, 체크박스 모양이 같아야 함.F-08 R-6
