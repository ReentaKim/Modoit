# Modoit 앱 아이콘 요청서

이미지 생성 도구로 macOS 앱 아이콘 원화를 만들어 주세요. 이 폴더에 `modoit-icon-a.png`, `modoit-icon-b.png`, `modoit-icon-c.png` 세 시안을 저장하면 됩니다. 코드 작성은 필요 없습니다.

## 앱 소개
Modoit은 macOS 메모 앱입니다. 핵심은 "메모를 쓰고, 그 메모를 그대로 바탕화면에 스티키 메모로 꺼내 둔다"입니다. 체크박스 할 일 목록을 자주 씁니다. 이름은 "Mo-Do-It(뭐든 해낸다)"에서 왔습니다.

## 그림 내용
- 흰 메모 카드 한 장 위에서, 노란 스티키 메모 한 장이 살짝 기울어진 채 앞으로 떠오르는 장면입니다. "꺼내 둔다"는 느낌이 나야 합니다.
- 스티키 메모에는 둥근 체크 표시 하나(완료된 할 일)를 단순한 도형으로 넣어 주세요. 뒤의 카드에는 회색 줄 2~3개만 둡니다.
- 글자, 숫자, 로고 문자는 넣지 않습니다.

## 스타일
- 현대 macOS(Big Sur 이후) 앱 아이콘 스타일입니다. 부드러운 입체감, 은은한 그림자, 깔끔한 그라데이션을 씁니다.
- 색
  - 배경: 따뜻한 미색에서 아주 연한 회색으로 가는 은은한 그라데이션
  - 스티키: 노랑(#F7C731 근처)
  - 체크: 진한 노랑 또는 짙은 갈색 계열
- 단순하고 큼직하게 그려 주세요. 16px로 줄여도 형태가 읽혀야 합니다.

## 꼭 지킬 것
- **1024×1024 정사각형, 캔버스 전체를 배경으로 꽉 채웁니다.** 둥근 모서리, 바깥 여백, 바깥 그림자, 투명 배경 모두 없이 그려 주세요. 둥근 모서리와 여백은 받은 뒤 따로 처리합니다.
- **Apple 메모 앱 아이콘(위쪽 노란 띠 + 줄 그어진 흰 종이)과 비슷해 보이면 안 됩니다.** Apple, Notion 등 기존 앱 아이콘을 흉내 내지 마세요.
