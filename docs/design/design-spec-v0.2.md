## 1. 바뀐 원칙
- **macOS 전용**: 글꼴 대체 목록에서 Windows 글꼴을 뺀다. 우클릭 메뉴와 메뉴 막대는 macOS 네이티브 메뉴를 쓴다.
- **아이콘은 Phosphor**: 기본 굵기 `regular`. 선택된 항목과 강조 상태만 `fill`을 쓴다. 직접 그린 아이콘은 모두 걷어 낸다.

- `◧` 사이드바 접기 버튼: 사이드바를 접으면 목록 툴바 왼쪽(신호등 버튼 오른쪽)으로 옮겨 간다. 폭은 180ms ease-out으로 바뀐다.
- `⇅` 정렬 버튼: 네이티브 메뉴(직접 정렬 ✓ / 이름순 / 최신순)를 띄운다.
- 목록 행의 `●`: 꺼낸 메모 표시. 스티키 색을 쓴 지름 9px 점이다.

## 4. 폴더 트리
- 단계마다 16px씩 들여 쓴다. 펼침 화살표(`CaretRight`, 14px)는 90° 회전 애니메이션(120ms)을 준다. 하위 폴더가 없으면 같은 폭만큼 비워 둔다.
- 폴더 아이콘: 닫힘은 `Folder`, 펼침은 `FolderOpen`, 선택은 `fill` 굵기와 강조색
- **구분선 행**: 높이 13px, 가운데에 1px `--hairline` 선. 좌우 여백은 항목과 같다. 마우스를 올리면 끌 수 있는 손잡이 커서를 보여 준다.
- **끌어 놓기 표시**
  - 사이에 놓을 때: 강조색 2px 가로선과 왼쪽 끝 6px 원. 들여쓰기는 놓일 단계에 맞춘다.
  - 폴더 안에 놓을 때: 대상 행 배경을 `--accent-soft`로, 테두리를 강조색 1.5px로 바꾼다. 600ms 머무르면 접힌 폴더가 펼쳐진다.
  - 놓을 수 없는 곳(자기 하위): 표시 없음, 커서 `not-allowed`
  - 끄는 동안 원래 행은 투명도 0.4로 둔다.
- **우클릭 메뉴(폴더)**: 새 하위 폴더 / 이름 변경 / 아래에 구분선 추가 / ─ / 휴지통으로 이동
- **우클릭 메뉴(구분선)**: 구분선 삭제
- 이름 변경은 행 안에서 바로 편집한다(입력 칸 테두리 강조색). Enter로 확정하고 Esc로 취소한다.

## 5. 메모 목록
- 그룹 순서: **고정됨**(📌 `PushPin` fill 14px + 제목) → 오늘 → 어제 → …
- 우클릭 메뉴: 고정 / 고정 해제, 스티키로 꺼내기 **또는** 스티키 다시 넣기(꺼내져 있을 때), 꺼내 둔 메모에서 빼기(스티키 정보가 있을 때), ─, 휴지통으로 이동 (FR-44)
- 끄는 동안: 행 미리보기는 반투명 카드(폭 220, 그림자)로 보여 주고, 사이드바 폴더 행이 놓을 대상으로 강조된다.

## 6. 편집기
- **읽기 전용 안내 막대(FR-43)**: 편집기 위쪽에 높이 36px, `--accent-soft` 배경으로 띄운다. "이 메모에는 Modoit이 지원하지 않는 서식이 있어 읽기 전용으로 열었습니다." 오른쪽에 [그래도 편집] 버튼을 둔다.
- **저장 실패 알림(NFR-13)**: 같은 위치에 빨간 계열(`#FF3B30`, 15% 배경) 막대. "저장하지 못했습니다 — 다시 시도 중…"
- **이미지**: 최대 폭 100%, 모서리 6px, 위아래 6px 여백. 선택하면 강조색 2px 외곽선. 불러오는 중에는 `--field` 배경 자리 표시(높이 120)를 둔다. 깨진 이미지는 `ImageBroken` 아이콘과 파일 이름을 보여 준다.
- **표**: 1px `--hairline` 칸 테두리, 머리글 행 배경 `--field`, 칸 여백 6×10px
- **`/` 메뉴**: 폭 280px, 최대 높이 340px, 모서리 10px, 시스템 그림자, 배경 `--pane`
  - 행 높이 36px: 아이콘 18px + 이름(15px) + 오른쪽 단축 표기(13px, `--text-3`, 예: `-`, `[ ]`, `#`)
  - 선택된 행: `--accent-soft`
  - 결과가 없으면 "결과 없음"

### 6.1 꺼내기 ↔ 다시 넣기 (FR-44)
- 편집기 툴바 버튼은 상태에 따라 바뀐다.
  - 꺼내져 있지 않으면 `ArrowSquareOut` "스티키로 꺼내기"
  - 꺼내져 있으면 `ArrowSquareIn`(강조색) "다시 넣기"
- 사이드바 "꺼내 둔 메모" 행
  - 열린 스티키는 진한 색 점, 넣어 둔 스티키는 흐린 점(투명도 0.45)
  - 마우스를 올리면 오른쪽에 버튼(열려 있으면 `ArrowSquareIn`, 넣어 뒀으면 `ArrowSquareOut`)
  - 우클릭: 꺼내기 또는 다시 넣기 / 메인 창에서 열기 / ─ / 꺼내 둔 메모에서 빼기

## 7. 스티키 (NSPanel)
- 창 동작
  - 다른 앱 위에 떠 있어도 클릭만으로는 그 앱이 비활성화되지 않는다.
  - 글을 입력할 때만 키 입력을 받는다.
  - 모든 데스크톱(Spaces)에 보인다.
- 상단 막대 높이 28px. 막대 버튼은 마우스를 올렸을 때만 보인다.
  - 색 점(13px)
  - `PushPin`(항상 위)
  - `ArrowSquareIn`(메인 창에서 이 메모 열기)
  - `X`(다시 넣기)
- 본문 글꼴은 설정의 글꼴을 쓰고, 크기는 설정 크기 − 1이다.
