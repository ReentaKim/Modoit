## 1. 모양 (FR-45)
- 설정 시트 맨 위에 "모양" 세그먼트를 둔다: `시스템 | 라이트 | 다크`.
- 구현 원칙: 앱 전체의 macOS appearance를 바꾼다. 웹 화면은 이미 있는 `prefers-color-scheme` 토큰을 그대로 따르고, 사이드바 반투명 효과·네이티브 메뉴·대화상자도 함께 바뀐다.
- 다크 토큰(v0.2 app.css)

  | 토큰 | 다크 값 |
  |---|---|
  | 본문 배경 | `#1e1e1e` |
  | 본문 글자 | `#f2f2f7` |
  | 목록 배경 | `#232323` |

  - 본문 대비는 15.9:1(NFR-15)이다.

### 1.2 스티키 막대 버튼 (BUG-38 관련 변경)
- 핀, 메인 창에서 열기, ✕(다시 넣기) 버튼은 **항상 보인다**. 평소 불투명도는 0.55이고, 마우스를 올리면 1이다.
- 바꾼 이유: 활성화되지 않은 macOS 패널에는 마우스 올림이 전달되지 않는다. v0.2처럼 올려야 보이는 방식이면 버튼이 끝내 나타나지 않아 "넣을 수 없다"는 문제가 생겼다.
- 색 견본은 지금처럼 마우스를 올릴 때만 보인다(보조 기능).

## 2. 강조 색 (FR-46)

## 3. 생성일·수정일 (FR-47)
- 편집기 위 날짜 줄(가운데 정렬, 13px, `--text-3`): `만든 날 2026년 11월 7일 오후 5:22  ·  고친 날 오후 6:34`
  - 같은 날이면 "고친 날"은 시각만 쓴다.
- 메모 목록 정렬 메뉴: `수정일순 | 만든 날짜순 | 이름순`. 행의 날짜와 날짜 묶음(오늘·어제…)은 정렬 기준 날짜를 따른다.

## 4. 토글 (FR-48)
- 왼쪽에 16px 삼각형(Phosphor CaretRight)을 두고, 펼치면 90° 회전(150ms)한다. 삼각형 영역은 24px이고 누르면 접힌다.
- 제목 줄은 본문과 같은 글자 크기다. 내용은 삼각형 오른쪽 선에 맞춰 24px 들여 쓴다.
- 빈 토글 제목의 안내 문구는 "토글", 빈 내용의 안내 문구는 "내용을 입력하세요"이다.

## 5. 입력 규칙 (FR-49, FR-50)
- `/` 메뉴 표기
  - 인용: `|`
  - 토글: `>`
  - 화살표 변환은 메뉴 항목이 아니다.
- 인용 블록의 모양은 v0.2와 같다(왼쪽 3px 선, `--hairline` 진하게).

## 6. 사이드바 "꺼내 둔 메모" (FR-31 개정)
- 지금 떠 있는 스티키만 나열한다. 하나도 없으면 구역 제목도 숨긴다.
- 행을 누르면 그 스티키를 앞으로 가져온다. 마우스를 올리면 다시 넣기 버튼(ArrowSquareIn)이 보인다.
- 우클릭 메뉴: 다시 넣기 / 메인 창에서 열기 / ─ / 다시 넣고 색·위치 기억 지우기
- 메모 목록 행의 색 점은 떠 있을 때만 보인다. 흐린 "넣어 둠" 점은 없앴다.

## 7. 설정·모양 진입점 (2026-11-07 사용자 피드백 "다크 모드를 어디서 바꾸는지 알 수 없다")
- 사이드바 맨 아래, 저장 폴더 버튼 오른쪽에 **톱니바퀴 버튼**(GearSix 18px)을 둔다. 누르면 설정 시트가 열린다. 툴팁: "설정 — 모양(다크 모드)·강조 색·글꼴 (⌘,)"
- 메뉴 막대 **보기 > 모양**: 시스템 설정 따르기 / 라이트 / 다크. 설정 시트를 열지 않고 바로 바꾼다.
- 설정 시트 안의 "모양" 세그먼트(1장)는 그대로 둔다.

## 8. v0.3 QA 반영 (BUG-43, BUG-44)
- 강조 색 위의 글자·체크 표시 색 토큰 `--on-accent`를 추가한다.
  - 라이트: 노랑·주황·초록·흑연은 `#1d1d1f`, 빨강·분홍·보라·파랑은 흰색이다.
  - 다크: 모두 `#1d1d1f`이다.
  - 다크 스티키는 `#1d1d1f`, 라이트 스티키는 흰색이다.
- 대비를 맞추려고 일부 색을 조정한다(2장 표 갱신).
  - 라이트 accent: 빨강 `#dc2c22`, 분홍 `#d6245e`, 파랑 `#006be8`. 흰 글자 대비 4.7 이상이다.
  - 라이트 link: 노랑 `#8a6400`, 주황 `#a35a00`, 초록 `#1f7a35`, 분홍 `#c2134f`. 흰 바탕 대비 4.5 이상이다.
- 스티키 창의 `/` 메뉴는 창 공통 토큰(`:root`)을 따른다. 다크에서는 바탕 `#2c2c2e`, 글자 `#f2f2f7`이다.

## 9. 앱 아이콘 (2026-11-08)
- 원화는 Codex 이미지 생성으로 만들었고, 요청서는 [`icon/brief.md`](icon/brief.md)에 있다. 시안 3개 중 사용자가 **c안(남색 다크)**을 골랐다.
  - 고른 이유: Dock·Finder에서 가장 눈에 띄고, 32px에서도 형태가 또렷하다.
- 그림: 흰 메모 카드 앞으로 체크 표시가 있는 노란 스티키가 기울어져 떠오른다. "메모를 꺼내 둔다"를 표현한다.
- 원화(`icon/modoit-icon-source.png`)는 꽉 찬 정사각형이다. 아래 규격은 스크립트로 처리했다.
  - 1024 캔버스, 824 크기의 연속 곡률 사각형(초타원 n=5), 아래쪽 그림자 12px
- 최종본 `icon/modoit-icon-1024.png`에서 `npx tauri icon`으로 `src-tauri/icons/` 전체를 만든다.
- Apple 메모 아이콘(위쪽 노란 띠 + 줄 노트)과 겹치지 않도록 요청서에 명시했다.
