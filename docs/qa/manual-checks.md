## 대기

### v2 개발판 (M8) — 위에서부터 차례로 한다
**준비:** 저장소 폴더에서 `macos/manual-test.sh --reset`. 개발판을 빌드하고 **연습용 폴더**(`macos/build/manual-vault`)로 연다. 실제 저장 폴더와 정식판 설정은 건드리지 않는다. 연습용 폴더에는 "업무"(할 일, 회의록), "개인"(긴 메모, 장보기, 여행/제주), "보관"이 들어 있다. "껐다 켠다"는 ⌘Q 뒤 `macos/manual-test.sh`(`--reset` 없이)다.

결과 칸에는 "통과" 또는 본 것을 그대로 적는다. 말로 알려 주면 AI가 적는다.

## 하지 않음
v2가 v0.x를 대체하고 스티키가 보기 전용이 되면서([D-25](../decisions.md)) 더 볼 필요가 없어진 항목이다. 대신 보는 v2 항목을 적는다.

| ID | 원래 확인하려던 것 | 하지 않는 이유 | 대신 |
|---|---|---|---|
| G-1, G-13 | v0.3: 모양(라이트·다크·시스템)이 모든 창에 바로 바뀌고 유지 | v2는 설정 화면을 새로 만들었다 | V2-M6 |
| G-8, G-15, G-17 | v0.3: 가려진 스티키를 다시 넣을 때 닫히고 저장되는지 | v0.3 웹 패널의 문제. v2 스티키는 네이티브 패널이고 입력이 없다 | V2-M13 |
| G-14, SP-02 | 스티키에서 쓴 직후 메인에서 한글을 치면 글자가 깨지는지 | 스티키에서 글을 쓰지 않는다 | V2-M15 |
| SP-01 | 스파이크와 v0.3이 같은 Markdown을 쓰는지 | 스파이크는 끝났다. 편집기는 같은 TipTap 번들이다 | V2-M5 |
| SP-03 | 2차 스파이크: 네이티브 스티키에 한글로 글쓰기 | 네이티브 스티키 편집을 없앴다 | V2-M11 |

### v0.4 — BUG-35 종료 전 저장 ([F-12](../product/features/F-12-quit.md)), 2026-11-09 대표 확인
준비: 실행 중인 Modoit을 종료하고 `open src-tauri/target/debug/bundle/macos/Modoit.app`. 각 항목은 입력하고 **0.5초 안에** 종료한 뒤, 다시 열어 마지막 글자가 남았는지 본다.

| ID | 방법 | 기대 결과 | 결과 |
|---|---|---|---|
| MC-01 | 메인 창 입력 → 바로 Dock 아이콘 우클릭 → 종료 | 글자가 남음 | **통과** |
| MC-02 | 한글 입력 상태로 입력 → 바로 ⌘Q | 글자가 남음 | 1차 앱 멈춤: ⌘Q 경로가 tao 이벤트 처리 안에서 `terminate:`를 불러 교착 → `quit.rs` `request`를 다음 런 루프로 미룸. 2차 **통과** |
| MC-03 | 스티키에 입력 → 바로 Dock에서 종료 | 글자가 남음 | **통과** |

확인 중 발견: 다시 켜면 마지막에 고른 메모가 선택되어 있지 않다. v0.3부터 없던 동작 → v2.0 요구사항 FR-53([D-18](../decisions.md)).
