## 완료

### v0.4 — BUG-35 종료 전 저장 ([F-12](../product/features/F-12-quit.md)), 2026-11-09 대표 확인
준비: 실행 중인 Modoit을 종료하고 `open src-tauri/target/debug/bundle/macos/Modoit.app`. 각 항목은 입력하고 **0.5초 안에** 종료한 뒤, 다시 열어 마지막 글자가 남았는지 본다.

| ID | 방법 | 기대 결과 | 결과 |
|---|---|---|---|
| MC-01 | 메인 창 입력 → 바로 Dock 아이콘 우클릭 → 종료 | 글자가 남음 | **통과** |
| MC-02 | 한글 입력 상태로 입력 → 바로 ⌘Q | 글자가 남음 | 1차 앱 멈춤: ⌘Q 경로가 tao 이벤트 처리 안에서 `terminate:`를 불러 교착 → `quit.rs` `request`를 다음 런 루프로 미룸. 2차 **통과** |
| MC-03 | 스티키에 입력 → 바로 Dock에서 종료 | 글자가 남음 | **통과** |

확인 중 발견: 다시 켜면 마지막에 고른 메모가 선택되어 있지 않다. v0.3부터 없던 동작 → v2.0 요구사항 FR-53([D-18](../decisions.md)).
