## 3. 규칙
| # | 규칙 | 이유 |
|---|---|---|
| R-1 | 폴더를 고르면 그 폴더 **바로 안**의 메모만 보인다. "모든 메모"는 전부 | v0.3과 같음 |
| R-2 | 행의 날짜는 정렬 기준을 따른다(만든 날짜순이면 생성일) | |
| R-3 | 이름순에서는 날짜 그룹 없이 즐겨찾기 + 나머지 | |
| R-4 | 떠 있는 스티키면 행에 색 점 | F-08 |
| R-5 | 즐겨찾기·꺼내기는 입력 중인 본문을 지우지 않는다 | 입력 보호 |
| R-6 | "고정"이라는 말은 스티키의 "항상 위"(F-08)에만 쓴다. 목록에 모으는 기능은 "즐겨찾기"다. 둘은 서로 영향을 주지 않는다 | v0.x에서 두 기능이 같은 이름이라 스티키를 넣으면 고정도 풀린다고 오해했다(D-21) |
| R-7 | 사이드바 "즐겨찾기"에서는 폴더와 관계없이 전부 보이고, 목록 그룹은 지금 보는 폴더 안의 즐겨찾기만 | 폴더를 고르면 바로 안의 메모만(R-1)과 같게 |

## 4. 동작
- 우클릭 메뉴: 즐겨찾기에 추가·해제, 스티키로 꺼내기·다시 넣기, 색·위치 기억 지우기, 휴지통으로.
- 메모 끌기: 입력 저장 → 바뀐 경로 기준으로 이동 → 상대 링크 재작성.
