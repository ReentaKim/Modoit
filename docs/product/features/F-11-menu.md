# F-11 메뉴·단축키

| 항목 | 내용 |
|---|---|
| 담당 | 기획 (검토: 디자인, 개발, QA) |
| 상태 | **검토 중** (프로토타입 검토 때 화면과 함께 확정, D-22) |
| 대상 버전 | v2.0 |
| 화면 | [프로토타입](../../prototype/index.html) SCR-07 |

## 1. 왜
macOS 앱답게 모든 명령을 메뉴 막대에서 찾을 수 있고, 단축키는 한글 입력 상태에서도 동작한다.

## 2. 요구사항
| ID | 약속 | MoSCoW | 수용 기준 | 검증 |
|---|---|---|---|---|
| FR-41 | 메뉴 막대 | Must | 4장 표. 단축키는 입력 소스(한글·영문)와 상관없이 동작 | M1 |
| FR-37 | 아이콘 | Must | 화면 안 기호는 SF Symbols(D-10). 앱 아이콘에는 쓰지 않는다 | M2 |

## 3. 규칙
| # | 규칙 | 이유 |
|---|---|---|
| R-1 | 결과가 메인 창에 보여야 하는 명령(새 메모, 새 폴더, 찾기, 설정, 정보, 저장 폴더 변경, 사이드바)은 메인 창을 먼저 보인다 | |
| R-2 | ⌘⇧S(꺼내기·넣기)와 ⌘⇧P(즐겨찾기)는 **메인 창에서 고른 메모**에 적용된다. 스티키에 포커스가 있어도 같다 | v0.3과 같음 |
| R-3 | Ctrl 조합은 가로채지 않는다 | BUG-13, 20 |

## 4. 메뉴 구성
| 메뉴 | 항목 | 단축키 |
|---|---|---|
| Modoit | Modoit 정보, 설정…, 서비스, 가리기, 기타 가리기, 모두 보기, Modoit 종료 | ⌘, ⌘Q |
| 파일 | 새 메모, 새 스티키 메모, 새 폴더 / 스티키로 꺼내기, 즐겨찾기에 추가 / 저장 폴더 변경… | ⌘N, ⌘⇧N, ⌥⌘N, ⌘⇧S, ⌘⇧P |
| 편집 | 실행 취소, 다시 실행, 잘라내기, 복사, 붙여넣기, 모두 선택, 찾기 | 시스템 기본, ⌘F |
| 보기 | 사이드바 보기·가리기, 모양(시스템 설정 따르기·라이트·다크) | ⌥⌘S |
| 창 | 최소화, 확대/축소, 메인 창, 열린 창 목록 | ⌘0 |
| 도움말 | macOS 메뉴 검색 칸 | — |

## 5. 검증

|---|---|---|
