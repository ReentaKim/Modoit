# F-09 검색

| 항목 | 내용 |
|---|---|
| 담당 | 기획 (검토: 디자인, 개발, QA) |
| 상태 | **초안** |
| 대상 버전 | v2.0 |
| 화면 | [프로토타입](../../prototype/index.html) SCR-02-B 검색창 |

## 1. 왜
메모가 많아져도 제목으로 바로 찾는다.

## 2. 요구사항
| ID | 약속 | MoSCoW | 수용 기준 | 검증 |
|---|---|---|---|---|
| FR-11 | 검색 | Must | ⌘F로 검색창에 커서. 입력하는 대로 걸러진다. Esc로 지운다 | A1 |

## 3. 규칙
| # | 규칙 | 이유 |
|---|---|---|
| R-1 | 대상: 제목, 미리보기, 경로. 대소문자 무시 | 본문 전체 검색은 백로그 B-02 |
| R-2 | 지금 보는 범위(고른 폴더 바로 안, 또는 모든 메모) 안에서만 찾는다 | v0.3과 같음 |
| R-3 | 새 메모를 만들면 검색어를 지운다 | 새 메모가 목록에서 안 보이는 일을 막는다 |

## 5. 검증
| ID | 무엇을 | 어디서 |
|---|---|---|
| A1 | 범위·대상·Esc | **신규 작성 필요** (v0.3에 검색 전용 테스트 없음) |
| M1 | 메모 수백 개에서 즉시 반응 | 수동 (NFR-05) |
