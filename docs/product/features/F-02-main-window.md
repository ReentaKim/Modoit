# F-02 메인 창

| 항목 | 내용 |
|---|---|
| 담당 | 기획 (검토: 디자인, 개발, QA) |
| 상태 | **초안** |
| 대상 버전 | v2.0 |
| 화면 | [프로토타입](../../prototype/index.html) SCR-02 |

## 1. 왜
폴더 / 메모 목록 / 편집기의 3단 화면은 Apple 메모와 같은 익숙한 구조다. v2에서는 진짜 macOS 컨트롤(SwiftUI)로 만든다(P-3).

## 2. 요구사항
| ID | 약속 | MoSCoW | 수용 기준 | 검증 |
|---|---|---|---|---|
| FR-04 | 3단 화면 | Must | 사이드바(모든 메모, 폴더 트리와 메모 수, 꺼내 둔 메모) / 메모 목록 / 편집기 | M1 |
| FR-25 | 사이드바 접기 | Must | 툴바 버튼, ⌥⌘S. 상태 기억 | M1 |
| FR-42 | 닫기 = 숨기기 | Must | 빨간 버튼으로 닫아도 앱과 스티키는 남는다. Dock 아이콘, ⌘0, 스티키의 "메인 창에서 열기"로 다시 보인다 | M2 |

## 3. 규칙
| # | 규칙 | 이유 |
|---|---|---|
| R-1 | 숨기기 전에 편집 중인 입력을 저장한다 | Brief 3.2-2 |
| R-2 | 창 위치·크기는 SwiftUI 기본 복원을 쓴다(v0.3은 기억하지 않았음) | 별도 구현 없이 macOS답게 |

## 4. 동작
- 결과가 메인 창에 보여야 하는 메뉴(새 메모, 새 폴더, 찾기, 설정, 정보, 저장 폴더 변경, 사이드바)는 메인 창이 숨어 있으면 먼저 보인 뒤 실행한다(F-11).
